LUNA FEM FINANCE v1.0 - LEIA-ME / MANUAL DE ATUALIZAÇÃO
========================================================

O QUE É ESTA VERSÃO
--------------------
A V1.0. Última fase do roteiro combinado: importação em massa de
produtos, margem de lucro na lista de produtos, revisão de design
responsivo, e documentação completa do projeto. Veja CHANGELOG-v1.0.txt
para os detalhes desta fase, e GUIA-COMPLETO-LUNA-FEM-FINANCE-v1.0.txt
para o manual de uso de todo o sistema.

COMO ATUALIZAR
--------------
1. Backup primeiro: Administrador > Backups > "Baixar backup JSON".
2. Substitua index.html, style.css e app.js pelos desta versão.
3. Abra o index.html. Seus dados aparecem automaticamente.
4. O Apps Script não muda nesta versão.

COMO IMPORTAR PRODUTOS EM MASSA (novidade)
----------------------------------------------
1. Administrador > Produtos > "+ Importar produtos em massa".
2. Cole os dados de uma planilha, ou selecione um arquivo .csv.
   Formato esperado (separado por ; ou ,), com esta linha de cabeçalho:
   nome;categoria;tipo;custo;preco;estoque;sku;fornecedor;observacoes
3. "Analisar" - confira quantos produtos serão criados e quantos serão
   atualizados (produtos com o mesmo SKU de um já cadastrado).
4. "Confirmar importação".
